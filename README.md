# Ровнее

Игровой трекер привычек для челюсти, дыхания и осанки: ежедневные квесты, дневник сна, «главы»-врачи, уровни и значки.

Сайт: https://rovnee.arpi-apps.workers.dev

## Что где лежит

```
public/
  index.html             — всё приложение (разметка, стили, логика)
  manifest.webmanifest   — чтобы можно было добавить на главный экран телефона
  icon.svg               — иконка
  sw.js                  — офлайн-режим
wrangler.jsonc           — настройки для Cloudflare
```

Квесты, врачи и значки задаются в начале скрипта в `public/index.html`:
`DEFAULT_QUESTS`, `DEFAULT_CHAPTERS`, `BADGES`. Новые квесты можно добавлять и прямо в приложении (вкладка «Ещё»).

Данные хранятся только в браузере (localStorage). Резервная копия — «Ещё» → «Скачать копию».

## Как подключить к Cloudflare, чтобы сайт обновлялся сам

1. Загрузите эту папку в новый репозиторий на GitHub.
2. Откройте Cloudflare → **Workers & Pages** → воркер **rovnee**.
3. **Settings** → **Builds** → **Connect** → выберите репозиторий.
4. Build command оставьте пустым, Deploy command: `npx wrangler deploy`.
5. Готово: каждое изменение в GitHub будет само выкладываться на сайт.

Если поменяете квесты по умолчанию, у вас в браузере останутся старые (они уже сохранены). Новые появятся после «Сбросить всё» — сначала скачайте копию — или добавьте их вручную во вкладке «Ещё».
