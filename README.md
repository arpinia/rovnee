# Ровнее

Игровой трекер привычек для тела: ежедневные квесты, дневник, «главы»-врачи, уровни, значки и общий прогресс с друзьями по коду.

Сайт: https://rovnee.arpi-apps.workers.dev

## Программы

При первом входе человек пишет имя и выбирает программу:

- **Челюсть, дыхание и осанка** — язык, челюсть, нос, шея.
- **Спина и шея при МФС** — только мягкие упражнения под миофасциальный синдром (видео тоже ищутся под МФС), шея, тепло; главы: невролог, проверка сколиоза, ЛФК, стоматолог и «зубы по одному».

Программы задаются в объекте `PROGRAMS` в начале скрипта в `public/index.html`.

## Напоминания

«Ещё» → «Напоминание раз в день»: выбрать час и включить. Уведомление приходит только если в этот день ещё ничего не отмечено. Работает через Web Push: воркер раз в час (cron) проверяет, кому пора. Закрытый ключ VAPID хранится в Cloudflare как секрет `VAPID_PRIVATE_JWK`, публичный — в `index.html` и `src/worker.js`.

## Темы

«Ещё» → «Тема»: обычная, неоновый закат, феи, комикс-герои, броня. Темы задаются CSS-переменными в конце `<style>` в `index.html`.

## Друзья

У каждого есть код из 6 символов. Друг вводит его во вкладке «Друзья» и видит уровень, XP, по каким дням были квесты и значки. Дневник и заметки о врачах не передаются. Можно отправить 💛 — «подбодрить».

## Что где лежит

```
public/
  index.html             — всё приложение (разметка, стили, логика)
  manifest.webmanifest   — чтобы можно было установить на телефон
  icon.svg               — иконка
  sw.js                  — офлайн-режим
src/worker.js            — маленький сервер для кодов и прогресса друзей
wrangler.jsonc           — настройки для Cloudflare (включая хранилище KV)
```

Остальные данные хранятся только в браузере (localStorage). Резервная копия — «Ещё» → «Скачать копию».

## Установка на телефон

Android: открыть сайт в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
iPhone: открыть в Safari → «Поделиться» → «На экран „Домой“».

## Автообновление сайта

(Уже подключено.) Каждое изменение в ветке `main` на GitHub само выкладывается на сайт через Cloudflare Workers Builds (Deploy command: `npx wrangler deploy`).

Если поменяете квесты по умолчанию, у вас в браузере останутся старые (они уже сохранены). Новые появятся после смены программы или «Сбросить всё» — сначала скачайте копию — или добавьте их вручную во вкладке «Ещё».
